## Controls

- **Scroll** to switch between CPU, memory and temperature.
- **Click** for the detail: load average, GiB used, or °F.
- **Right click** opens the dashboard.

Its page in **Settings → Plugins** sets what it shows first, how often it
updates, when it turns red, and whether the ring shows.

The view is `plugin.facet`; `bin/sysmon.py` only measures.
